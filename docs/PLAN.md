# План и шаги

Задание: веб-приложение, где AI превращает одну математическую задачу в 3 уровня сложности.
Сдать нужно: **живую ссылку**, **публичный GitHub-репозиторий с README** и **отчёт на 1 страницу**.
Дедлайн: пятница, 10:00.

## Что уже сделано

- [x] Тема: площадь треугольника (Ұшбұрыштың ауданы)
  - Уровень 1: основание и высота, $S=\frac12 ah$
  - Уровень 2: две стороны и угол между ними ($S=\frac12 ab\sin C$) или три стороны (формула Герона)
  - Уровень 3: прикладная многошаговая задача (сначала найти недостающую высоту, работа с координатами и т.п.)
- [x] Фронтенд: выбор уровня, генерация задачи, пошаговые подсказки, решение, поле ответа
- [x] Бэкенд: `/api/generate` и `/api/check` как функции Vercel, ключ хранится только на сервере
- [x] Промпты для трёх уровней в `lib/prompts.js` (пока черновик)
- [x] Проверка математики кодом: `lib/math.js` сам считает площадь (4 способа), неверные задачи генерируются заново
- [x] Тесты (`npm test`), локальный сервер (`npm run dev`), README

## Что нужно от тебя

1. **Ключ Gemini.** Получи бесплатно на https://aistudio.google.com/apikey (нужен Google-аккаунт).
   Не присылай его в чат и не коммить: он вставляется в `.env` локально и в настройки Vercel.
2. **Аккаунт Vercel.** Зарегистрируйся на https://vercel.com через «Continue with GitHub».
3. **Подтверждение на создание репозитория.** Я могу создать публичный репозиторий через `gh`
   (ты залогинен как `Serdar0000`) и запушить код. Скажи имя репозитория или «давай».
4. **Своя работа.** По правилам курса код, промпты и отчёт должны быть твоими. Обязательно:
   - перепиши промпты в `lib/prompts.js` своими словами и поэкспериментируй с ними;
   - разберись в каждом файле, чтобы суметь объяснить его на защите;
   - напиши `REPORT.md` сам (заготовка с разделами лежит в репозитории).

## Шаги

### 1. Запуск локально
```bash
cp .env.example .env        # вставь ключ в GEMINI_API_KEY=
npm run dev                 # открой http://localhost:3000
```
Проверь все 3 уровня: задача генерируется, формулы отображаются, подсказки и проверка ответа работают.

### 2. Проверка математики (в задании прямо сказано, что за это снимают баллы)
- Сгенерируй по 5–10 задач на каждом уровне и реши несколько вручную.
- Убедись, что сходятся условие, данные треугольника, решение и ответ (особенно на уровне 3: совпадают ли числа в тексте с теми, по которым считается площадь).
- Если модель ошибается, усиль промпт и запиши это в отчёт как итерацию.

### 3. GitHub
```bash
git add . && git commit -m "Initial version"
gh repo create quadratic-differentiator --public --source=. --push   # уже сделано
```

### 4. Vercel
1. vercel.com → **Add New → Project** → импортируй репозиторий.
2. Framework Preset: **Other**. Остальное оставь по умолчанию (`vercel.json` уже указывает папку `public`).
3. **Environment Variables**: `GEMINI_API_KEY` = твой ключ.
4. **Deploy**. Получишь ссылку вида `https://quadratic-differentiator.vercel.app`.
5. Открой ссылку и проверь все 3 уровня ещё раз.
6. Вставь ссылку в README (строка «Live demo»), закоммить и запушь. Vercel передеплоит сам.

### 5. Отчёт (1 страница)
Заполни `REPORT.md` (можно экспортировать в PDF). Что должно быть:
- какие промпты использованы (base и три уровня) и почему;
- как достигается дифференциация: числа, контекст, количество подсказок, стиль обратной связи;
- как проверяется правильность (код пересчитывает площадь, повторная генерация);
- 1–2 примера задач на каждом уровне.

### 6. Сдача
- Live URL
- Ссылка на GitHub
- Отчёт

## Если что-то не работает
| Симптом | Причина |
|---|---|
| `GEMINI_API_KEY is not set` | Нет ключа в `.env` (локально) или в Vercel → Settings → Environment Variables. После добавления нужен Redeploy |
| `Gemini request failed (429)` | Превышен лимит бесплатного тарифа, подожди минуту |
| «The AI is busy right now, so this is a built-in practice task» | Все модели исчерпали бесплатный лимит, работает запасной генератор. Лимиты сбрасываются раз в сутки |
| Хочется другие модели | Задай `GEMINI_MODELS=модель1,модель2` в `.env` и в Vercel |
| Формулы показываются как `$x^2$` | Не загрузился KaTeX с CDN, проверь интернет или блокировщик |
